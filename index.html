วิธีตั้งค่า Firebase
  1. เข้า console.firebase.google.com แล้วสร้างโปรเจกต์
  2. เมนู Build > Realtime Database > Create Database (แนะนำภูมิภาค Singapore)
  3. คัดลอก URL ที่อยู่ด้านบนของหน้า Data มาวางในช่อง Database URL
  4. แบบปลอดภัย: ตั้ง Rules เป็น {"rules":{".read":false,".write":false}} แล้วนำ Database Secret (Project settings > Service accounts > Database secrets) มาวางในช่อง Secret
  5. แบบง่าย: ไม่ใส่ Secret แต่ต้องเปิด Rules ให้ .read และ .write เป็น true ซึ่งใครที่รู้ URL ก็อ่าน/เขียนข้อมูลได้
